# Поведінкова аналітика

GA4 використовується для аналізу дослідження, а не для підтвердження випуску чи використання фінансових карток. Дані до оновлення інтерфейсу та після нього порівнюю окремо. Відвідувачів, кількість подій і сеанси не змішую.

## Шлях користувача

`card_view → card_detail_click → card_detail_view → section_view / взаємодія → card_open`

На сторінку картки можна прийти з пошуку чи прямого посилання. Відсутність попереднього `card_detail_click` у такому випадку очікувана. Сортування та сторінка рейтингу — додаткові способи вибору.

| Подія | Значення |
|---|---|
| `card_view` | Щонайменше половина зображення картки на головній потрапила у видиму область активної вкладки. Один раз для картки за завантаження сторінки. |
| `card_detail_click` | Натискання внутрішнього посилання на сторінку картки; `placement` відділяє зображення, кнопку, назву, рекомендацію чи таблицю. |
| `card_detail_view` | Сторінка картки відкрита у видимій вкладці. Один раз за завантаження. |
| `section_view` | Щонайменше половина заголовка розділу потрапила у видиму область активної вкладки. Один раз для розділу за завантаження. |
| `detail_open` | Відкрито розрахунок: purchase / cashback / earning / funding / losses. Відкриті за замовчуванням панелі не рахуються як натискання. |
| `criterion_open` | Відкрито пояснення критерію на сторінці картки або методику критерію в рейтингу. |
| `faq_open` | Відкрито конкретну відповідь; `faq_id` стабільний між мовами, аналізується разом із `card_id`. |
| `flow_interaction` | Розгорнуто чи згорнуто процес або маршрут, відкрито пояснення, натиснуто центр, умістити, масштаб або скидання. Автоматичне компонування і перетягування не рахуються. |
| `chart_change` | Завершено зміну бюджету чи бази розрахунку кешбеку. `change`, а не кожен `input` під час перетягування. |
| `sort_change` | Вибрано score / gross / potential / actual. Початкове сортування не є взаємодією. |
| `ranking_open` | Натискання посилання на сторінку рейтингу з іншої сторінки. Внутрішні якорі рейтингу не є новим переходом. |
| `evidence_open` | Відкрито галерею або оригінальний PNG; окремо умови Prime. |
| `card_open` | Натискання посилання на сайт сервісу картки. `is_referral` відділяє звичайне посилання від реферального. Це не підтверджена реєстрація чи випуск картки. |
| `language_switch` | Перемикання мови сайту. |
| `repository_click` | Перехід до GitHub із шапки чи футера. |

Видимість зображення чи заголовка не доводить прочитання. Повторне розкриття — нова дія, тому кількість подій не дорівнює кількості людей. Фонові вкладки не створюють `card_view`, `card_detail_view` чи `section_view` до переходу користувача на них. За відсутності IntersectionObserver кліки працюють, але покази карток і заголовків не обчислюються.

## Спеціальні виміри GA4

Усі мають область **Event / Подія**. `page_type` та `page_language` спільні для власних подій, а `card_id` автоматично додається на сторінці картки. У події переходу `card_id` означає цільову картку.

| Параметр | Для чого |
|---|---|
| `card_id` | Картка |
| `page_type` | home / card / ranking |
| `section` | Розділ або тип розрахунку |
| `sort_mode` | Режим сортування |
| `is_referral` | Реферальне чи звичайне посилання |
| `placement` | Місце посилання; для зовнішнього переходу — тип сторінки |
| `page_language` | Мова вмісту, а не налаштування браузера |
| `target_language` | Мова після перемикання |
| `evidence_type` | transactions / prime_terms |
| `evidence_view` | gallery / original |
| `criterion` | Критерій рейтингу |
| `faq_id` | q1, q2 тощо |
| `flow_process` | Процес у схемі |
| `flow_route` | Ідентифікатор маршруту |
| `interaction_action` | expand / collapse / info / center / fit / zoom_in / zoom_out / reset |
| `chart_basis` | payout / after_fee |
| `budget_band` | zero / 1_500 / 501_1000 / 1001_2000 / 2001_3500 / 3501_5000 |

Після реєстрації вимірів нові розрізи стають доступними у звітах зазвичай через [24–48 годин](https://support.google.com/analytics/answer/14239696?hl=en). Не розраховую на автоматичне відновлення історичних розрізів, яких не було під час збору.

## Практичні звіти

1. **Зацікавленість картками:** рядки `card_id`, стовпці `eventName`, метрики Total users та Event count; окремо card_view / card_detail_click / card_detail_view / card_open. Порівнювати людей і події окремо, покази не називати прочитанням.
2. **Розділи, які вивчають:** section_view та detail_open за `section`, `card_id` і `page_type`. Відкриті за замовчуванням розрахунки оцінювати за видимістю розділу та взаємодіями, а не за кількістю розкриттів.
3. **Схеми та пояснення:** flow_interaction за `flow_process`, `flow_route`, `interaction_action`; FAQ за `faq_id` та критеріями за `criterion`.
4. **Вихідні переходи:** card_open за `card_id`, `is_referral`, `page_type` та джерелом сеансу. Основна подія card_open — сигнал інтересу до сервісу, а не продаж чи випуск картки.
5. **Джерела:** Sessions, Engaged sessions та переходи card_open за Session source / medium. Для дописів додавати зрозумілі UTM-мітки; Direct не означає, що всі вручну ввели адресу.

Фільтр публічного домену потрібен для старих даних: попередні локальні прев’ю надсилали аналітику. В оновленій версії тег завантажується лише на HTTPS-адресі опублікованої canonical-сторінки. `localhost`, `127.0.0.1`, file:// та копії за іншими адресами не завантажують тег і не надсилають власних подій.

Автоматичний GA4 `click` і власний `card_open` можуть описувати той самий перехід. Не підсумовувати їх як окремі конверсії. Автоматичний [scroll означає досягнення 90% сторінки](https://support.google.com/analytics/answer/9216061?hl=en), а не прочитання всього вмісту.

## Перевірка і приватність

`node scripts/check-analytics.cjs` перевіряє реальні обробники в ізольованому середовищі без Google і мережевих запитів: обидві мови, 22 сторінки, переходи, чотири сортування, видимість, повтори, фонові вкладки, відсутній тег та виключення прев’ю. Після погодженої публікації нові події додатково звіряються в Realtime. Версія analytics.js у URL залежить від вмісту файлу, щоб браузер отримав оновлені обробники.

Власні події містять лише публічні ідентифікатори, категорії та ознаки дій. Для калькулятора передається діапазон умовного бюджету; точне значення не надсилається власною подією. Тексти відповідей, вміст доказів, реквізити, адреси гаманців, рухи миші й персональні дані не додаються. Автоматичні події Google мають власні стандартні параметри, зокрема URL сторінки й вихідного посилання.
