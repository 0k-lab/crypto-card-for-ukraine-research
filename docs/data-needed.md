# Що ще не підтверджено

Контрольна покупка, історичні USD-приклади та тести поповнення / виведення вже описані на сторінці й у даних. Нижче залишив лише питання, які потребують уточнення; невідомі витрати не рахую нульовими. Додаткові покупки спеціально для дослідження поки не планую.

## Виплати й завершення

- Зарахування BTC-кешбеку Kolo саме за контрольний чек; показану суму вже враховано за фіксованою розрахунковою оцінкою.
- Конвертація зарахованих Bybit points у USDT і доступність показаного кешбеку COCA / Solid.
- Завершення й фактичне надходження виведень Trustee Plus та WhiteBIT. Для Trustee також бракує внутрішнього card → wallet ledger і gas третього внеску; для WhiteBIT — мережі вводу й sender gas.

## Тарифи й програми

| Картка | Що уточнити |
| --- | --- |
| Bybit | Активну регіональну програму, cap базового tier, кваліфікацію наступного; ступені Auto-Earn й фактичні виплати |
| COCA | Активний tier, stake / промознижку, вільну claim capacity; суперечності no lockup / staking та unlimited APY / невказаного cap |
| Keyone | Активний план і деталізацію початкової різниці поповнення на fee / конвертацію |
| Kolo | Дату випуску й стартові 30 днів; вплив розмірів чеків на per-purchase cap; завершений внутрішній withdrawal ledger, якщо він доступний |
| OKX | Тариф і доступність інших мереж, USD-оцінку OKB gas на момент тесту; механізм майбутньої субсидії не встановлено |
| Simple | Точне початкове зарахування, складові номінальної різниці, кінцеве відшкодування relayer / paymaster; cap і фактичні виплати Earning |
| Solid | Деталізацію cross-chain різниці; придатність категорійних підписок; фактичне отримання Savings, доступність для оплати, мережеві витрати та умови Credit |
| Trustee Plus | Деталізацію fee / конвертації й причину розбіжності показаних доступних сум |
| WhiteBIT | Придатні MCC й активні категорії, регулярні виплати; повний цикл вводу / виводу |

Юридичних емітентів конкретних карток потрібно звірити з індивідуальними Cardholder Agreements або підтримкою. BIN-бази є допоміжними; суперечності OKX, WhiteBIT і публічної програми Kolo не вирішені.

## Межі поточного тесту

Не виміряні сталість курсу й fees на інших розмірах покупок, прийняття різними платіжними шлюзами, реальний дохід на залишку за тривалий період та окупність токенового капіталу для tier. Відомі історичні відмови збережені, але не доводять поведінку всіх продавців. Share Card Kolo вже працює — повторно перевіряти цей факт не потрібно.

Нові докази мають уточнювати ці питання. Особисті реквізити, адреси, хеші, номери карток та KYC-документи для публічних висновків не потрібні. Для нової операції є [шаблон запису](test-template.md).
